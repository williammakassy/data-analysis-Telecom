# data-analysis-Telecom
Telecom companies offer a variety of bundles (daily, weekly, monthly, data, airtime). However, customer preferences vary by age group, device type and usage behavior. Without proper analysis, it's difficult to identify which bundles drive the most engagement and revenue

Problem Statement
'The project aims to analyze customer bundle preferences in a telecom company, focusing on usage trends across age groups, bundle types and device categories.'
'The goal is to uncover actionable insights that can guide product design, marketing strategies, and customer retention initiatives.'
